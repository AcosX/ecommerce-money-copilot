# 登录页素材

两张图片分别使用 ImageGen 生成，不包含表单、品牌文字或按钮。

| 文件 | 用途 | 尺寸 | 比例约束 |
| --- | --- | --- | --- |
| login-island.webp | 小商、柯基与浮岛店铺，带透明通道 | 1000×1000 | 前景始终 contain，不裁切或拉伸 |
| login-sky.webp | 远景天空与云朵 | 1536×1024 | 背景 cover，可按视口裁切 |

源 PNG 位于本机 Codex generated_images 中；仓库保留经 WebP 压缩的发布素材。透明背景保留。纸张边框、邮戳、Microsoft 图标、密码图标与文字均由 HTML/CSS/SVG 实现。
