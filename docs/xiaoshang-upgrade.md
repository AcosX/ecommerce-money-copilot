# 小商对话与提交体验更新

## 行为

- 小商使用更新后的角色提示词及第一关规划技能，逐步引导玩家，生成完整 HTML 生意规划报告；方向评分不作为关卡通行条件。
- 聊天支持最多三张 JPEG、PNG 或 WebP 图片，也可仅发送图片。浏览器将图片缩至最长边 1280 像素、每张 200 KB 以内；服务端再次校验图片内容、类型、体积与像素数。图片直接传给支持视觉的模型，缺少服务时明确说明无法识图。
- 勾选“联网搜索”或提出明确的公开信息检索问题时，通过服务端 AnySearch 获取来源，再提供给模型。搜索内容按外部资料处理，回答附来源链接。搜索不可用或无结果时明确提示。
- 关闭按钮隐藏整个小商区域并中断语音；“打开小商”按钮恢复聊天，原有页面控件可以继续使用。
- 六关任务信件中的黄色“提交本关成果”按钮紧接“和小商聊一聊”，尺寸保持一致。生成报告后仍由玩家主动提交。
- 有效提交立即通过并解锁下一关；后台 AI 建议保留，但不会否决或阻塞进度。人工审核 API 和页面不再挂载。权限、版本冲突、证据归属以及提交快照约束继续生效。

## 配置与迁移

在服务端环境中填写以下变量（仓库仅包含空密钥占位）：

```dotenv
EMC_ANYSEARCH_API_KEY=
EMC_ANYSEARCH_BASE_URL=https://api.anysearch.com
EMC_ANYSEARCH_TIMEOUT_SECONDS=8
```

未填写密钥时不发起搜索请求。当前验证使用模拟上游响应，真实 AnySearch 调用需要配置有效密钥后验收。模型需支持 OpenAI 兼容的 `image_url` 消息格式。

Alembic `0004_self_submit` 将历史待审提交改为通过，保留原始快照与附件，并重新排队等待人工处理或持有旧租约的建议任务。回滚迁移保留已通过结果，将新提交方式映射为旧版本支持的方式。

图片不写入浏览器持久化历史；页面中的已发送缩略图只保留有限的临时记录。原生语音准备请求中的图片随既有轮次完成清理流程释放。

## 验证

- 后端覆盖图片校验、视觉请求、普通与原生语音传输、搜索接口及错误降级、立即通过、建议任务、权限隔离和历史数据迁移。
- 前端单元测试与既有浏览器回归继续运行。
- 新增浏览器回归覆盖桌面六关，以及 790、390、320 像素宽屏幕的关闭重开、图片选择与发送、搜索参数和提交按钮布局；已纳入 GitHub Actions。
