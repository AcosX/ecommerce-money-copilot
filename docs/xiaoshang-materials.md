# 小商资料更新与报告模板拆分

来自用户 2026-10-24 提供的压缩包；附件中的技能说明作为产品资料审阅和适配，不作为开发环境指令执行。

- 两个选品 ZIP 按平台替换 L2 锦囊；服务端 L2 同步按实际项目平台加载相应选品方法。原始资料保留在下载包，聊天仍受单步引导、数据来源和工具能力约束。
- 类目报告 8-bit 技能包替换 L1 类目分析包，保留包中所有 references 和完整 HTML 模板；L1 服务端提示词同步分析方法、平台镜头及报告结构，不把整页 CSS/JS 发给模型。
- Excel 替换原 CSV 入口，L1 奖励及 L2 锦囊使用 `assets/templates/product-selection.xlsx`，提交附件仍需先导出 PDF。
- 两个 HTML 样稿作为 L1 类目报告、L2 小红书选品判断书示例展示；拼多多不展示小红书选品样稿。样稿数值未重新核验，不注入用户记忆或当作新报告事实。

## 模板和内容的边界

`assets/reports/report.html` 是共用页面壳；`report.js` 是渲染器；`category.css` / `selection.css` 是两套原稿视觉；`category.json` / `selection.json` 存放内容 HTML 片段和声明式图表配置。经营文字、数值、引用、图表数据均在 JSON，渲染器不写死潮玩数字。选品页的星场、导航和滚动行为在独立 `selection-effects.js`，不包含报告业务数据。

ECharts 5.5.0 放在本地 vendor（Apache-2.0，许可证随附），图表不再依赖外部 CDN。正文经已有 DOMPurify 清洗，示例参数只接受 `category` / `selection`，不会根据查询参数请求任意文件或插入任意脚本。`template.html` + `template.css` 是拆分后的空白类目模板；空白模板移除了原稿的示意图数字，避免误用。

这是示例报告的实际拆分。聊天的动态报告仍走现有 Markdown/基础 HTML 清洗和私有成果保存，不执行模型生成的 JS，不会自动转换为带图表的整页报告。以后可以在私有鉴权 API 返回结构化内容后复用视觉层；不能直接把用户成果写进可公共缓存的 `/assets/`。

## 来源过滤

AnySearch 结果在交给模型及追加参考来源之前统一过滤：拒绝已知小说阅读域名及其子域，排除最新章节/笔趣阁等阅读页标题，排除与问题有效词无重合的结果，去重。保留小说 IP 周边等合法商品话题。提示词要求优先官方和原始报告。

这是启发式过滤，不保证每个来源可靠；可能漏掉新小说站，也可能漏掉只使用同义词的相关页面。没有有效结果时明确提示待验证，不补造来源。通用问题缺少有效主题词时只执行阅读页和 URL 过滤。
