# 单步带关与真实审核（2026-10-23）

关联 #61、#62、#66、#67。本次把关卡任务与唯一小商聊天串成一条路径：看清最后要交的成果，点击“让小商带我开始”，小商每次只问一个问题，用户要求整理成果后才打开检查提交页。没有并排工作纸或常驻锦囊入口；方法包在当前步骤需要或用户主动要求时提供。语音和形象设置折叠，岛上气泡不重复展开聊天中的长消息。

## 交付要求

| 关卡 | 成果 | 接收方式 |
| --- | --- | --- |
| L1 | 生意规划 | 至少 40 字文本，或 PDF/图片 |
| L2 | 选品单/报告 | 至少 40 字文本，或 PDF/图片 |
| L3 | Before/After 素材 | 两组对应图片 |
| L4 | 上架记录 | 在售截图或 http(s) 商品链接，工具记录选填 |
| L5 | 发布记录 | 发布成功截图，工具记录选填 |
| L6 | 复盘 | 至少 40 字文本，或 PDF/图片；没有订单也可以 |

上述是提交受理规则，通过仍要看核心成果。链接当前只作为提交信息，不抓取任意网址；模型不得假称打开链接，无法核实在售时应要求截图。L1/L2/L6 不要求把聊天报告重复导出附件。

`js/emc-journey.js` 与 `backend/emc_api/data/level_guides.json` 的标题、目标、检查项和文件槽通过契约测试保持一致。当前用户选中的关卡优先，不以关键词或全局进度把聊天切到其他关。已提交的前序成果在同项目范围内提供给小商。聊天草稿按关卡隔离。

## 提交与审核

正式提交在同一事务中冻结成果、绑定证据并创建 `review_jobs`。提交成功立即解锁下一关，审核完成不会切走用户当前关卡。审核记录包含真实 `source=agent`、模型、rubric 版本、快照散列、逐项依据与改进建议；没有模拟分数。模型失败不会变成玩家驳回。

独立 worker 以数据库租约领取任务，调用模型时不持有行锁；最多尝试 4 次，退避 30/60/120 秒。进程中断 120 秒租约到期后可恢复，多 worker 用 `SKIP LOCKED` 避免重复领取。写回前再次检查租约、快照、当前修订和待审状态，人工决定和新修订优先。低置信度、扫描 PDF 或不可读证据保留待复核。管理员仍可沿既有审核接口处理。

图片实际解码后发送给兼容多模态接口；文本 PDF 用 pypdf 提取，最多 30 页、48,000 字符；不冒充 OCR。文件大小与 SHA-256、所属玩家/项目和成果快照均验证。审核模型必须支持图片输入及 JSON 输出；不支持时任务重试/转复核，不退化成关键词通过。当前成本限制为单 worker、每次 2,400 输出 token、25 秒期限和每任务 4 次；尚无全局金额预算。

## 移除的演示能力与边界

已移除本地模拟通关、演示开关、演示证书与旧工作台的占位图片提交逻辑。教学方法包、明确标注的选品表例子仍是可下载的学习资料，不代表经营证据。旧 `tutorial_copy` 来源只为历史数据读取兼容保留。

网页端已切换为真实 `XingyunAvatarAgent`：原生 WebSocket 问答、流式模型事件、自动播报、主动开启的语音识别、打断和断开。自定义 Brain 通过短时受控回调连接现有小商服务，因此仍使用真实关卡、项目、知识库、工具与个人历史。没有另建一套聊天或使用平台默认“豆包”人设。详见 [网页端接入](./xingyun-web.md)。

这是 #67 的 Web E2E 接入验证；自定义 Brain 的业务编排仍在 FastAPI。星云平台托管业务 Agent 的自定义工具/长期记忆迁移、Dify/Coze 接入不在本次完成范围。

六关审核后的正式一致性结业审核、正式证书签发/撤销和独立首单成就仍属于 #66 后续范围。页面只呈现真实审核进度，不展示可误认已获证的预览或占位首单按钮。没有接管玩家电商账号，也不会擅自发布商品或内容。

## 复核方式

- `node --test js/tests/*.test.cjs`：交付契约、单步提示与纯函数。
- `backend/.venv/bin/pytest -q`（在 backend 下运行，指定独立 MariaDB 测试 URL）：审核事务、租约、重试、人工并发、新修订、真实文件处理与模型响应校验；不会调用付费模型。
- `js/tests/emc-journey-browser.cjs`：API 夹具回归六关、1440/390px；只验证界面、分组上传与幂等重试，不作为真实模型验收。
- `js/tests/emc-xingyun-web-live.cjs`：真实 Web E2E、真实模型与数据库，1440/390px 的任务、对话、报告、提交、L2 和锦囊；确认回复由原生通道返回且自动播报。
- `js/tests/emc-focus-flow-browser.cjs`：独立真实后端及模型，两种屏幕尺寸走任务、聊天、整理报告、冻结提交、下一关和按需锦囊。需 `EMC_TEST_SESSION_FILE` 指向仅限隔离环境的私有会话配置，且不可放入仓库。

所有开发库、私有配置、日志和截图均留在 Instabox；未写入生产数据库。
