# 电商搞钱参谋 · AI 副驾版 Demo

游戏化带教 × 真实经营结果驱动。每一关都在真实电商平台拿到真实结果才解锁，最终通关 = 破零动销（真实第一单）。

## 项目简介

一个纯前端单页 HTML 应用，把「从 0 到 1 做电商」拆成 6 个可验证的关卡，并内置一个 AI 向导「小商」作为副驾：

| 关卡 | 名称 | 目标 | 掉落道具 |
|------|------|------|----------|
| L1 | 生意规划 | 判断机会点 / 定平台类目 / 设第一单目标 | 定位向导 |
| L2 | 选品落地 | 四源商机情报 / 选品评估打分 / 产出选品单 | 商机雷达 |
| L3 | 素材优化 | 文生图出素材 / 素材自检 / 产出素材包 | 素材工坊 |
| L4 | 自动化上架 | 绑定平台 / 一键上架 / 上架记录核查 | 上架助手 |
| L5 | 内容生成发布 | 爆款文案 / 发布前人工审核 / 发布定时 | 内容魔法 |
| L6 | 数据复盘 | 数据回传 / 归因分析 / 策略调优反哺 | 数据罗盘 |

## 核心机制

- **真实结果驱动解锁**：每关任务完成后提交核验，核验通过才解锁下一关，杜绝「纸面通关」。
- **真实结果核验谱系**：平台能力决定可用档位，支持降级但不降低验收下限：
  - S1 数据直连（官方 API / OAuth，最强但需资质）
  - S2 授权采集（浏览器自动化读商家后台）
  - S3 公开核验（站内可见：在售/销量/评价/笔记）
  - S4 凭证举证（水印截图/录屏/物流单号轨迹）
  - S5 行为链 + 人工抽检（操作留痕 + 导师抽检）
- **破零强证据**：物流单号轨迹（快递 API 全网可查）——不依赖平台开放权限的硬证据。
- **AI 副驾情绪系统**：向导「小商」根据提问质量调整亲密度，高质量经营问题提升亲密度，达到阈值解锁隐藏福利（隐藏任务、加速道具、专属素材模板）。

## 快速开始

无需构建、无需依赖安装，直接浏览器打开 `index.html` 即可体验：

```bash
open index.html
```

## 技术栈

- 纯原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- 像素风 UI（Press Start 2P 字体 + 自定义 CSS 变量主题）
- 单文件结构，便于二次开发与部署
