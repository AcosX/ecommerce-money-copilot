# 类目生意参谋 · 8-BIT 报告版

开店或拓品的**第一站方向判断**：完成三段式生意分析（是不是好赛道、有没有机会、是不是你的机会），并把结论渲染成 8-bit 像素街机风的单文件 HTML 报告。分析结论与视觉是一体的——先做对分析，再套 UI。

## 定位与边界

- **做**：细分赛道级别方向判断、竞争与机会扫描、自身资源匹配、进入路径建议；HTML 报告自带 8-bit 像素街机 UI。
- **不做**：不算毛利/定价/启动资金（留给选品环节）；不判断具体某一款货；不做行业深度研报；不代替实地验证供应链。
- **颗粒度**：细分赛道（如 女装>连衣裙>法式碎花裙），不从大类直接下结论。
- **平台**：用户指定一个平台（小红书 或 拼多多），按该平台镜头分析，不做双平台横向比较。

## 工作流

### Step 1 · 对话挖掘（一轮只问 2-3 个，缺什么问什么）

1. **指定平台**：小红书 / 拼多多（未定时先问）。
2. **意向赛道**：允许模糊想法，协助收敛到细分层；记录用户原话。
3. **货源**：自有工厂 / 产业带 / 1688 拿货 / 无货源。
4. **内容或达人能力**：能否持续产出内容、有无达人/买手资源、审美或手艺。
5. **资金与库存承受力**、可投入时间、相关经验。

信息不足导致第③段无法打分时，**明确标注"待填"，不强行出 GO/NO-GO**。

### Step 2 · 选定平台镜头

按指定平台读 `references/platform-lenses.md`，用对应指标评估，不混用两套口径。

### Step 3 · 联网公开取证

- 公开检索收集：市场规模/增速、站内热度、竞争格局、价格带、人群、风险信号。
- **多口径并列**：不同机构数字冲突时并列呈现并注明口径，不取单点、不调和编造。
- **查不到就写"公开信息有限/待验证"**，绝不补造；用户可随时补截图或后台数据。
- 合规：只用公开合法内容，不绕过登录态/付费墙/反爬。

### Step 4 · 三段式打分（1-10）

| 段落 | 权重 | 评估维度 |
|---|---|---|
| ① 是不是好赛道 | 30% | 需求规模/搜索热度、增速趋势、季节性与时机、平台大盘适配 |
| ② 有没有机会 | 30% | 竞争密度/同质化、头部集中度、价格带或风格空白、进入门槛 |
| ③ 是不是你的机会 | 40% | 货源、内容/达人能力、资金库存承受力、经验、与平台玩法匹配及差距 |

**综合分 = ①×30% + ②×30% + ③×40%**（③缺失则综合分无法计算）。

**判定阈值（可按用户偏好微调，报告中写明所用阈值）**：≥ 7.5 GO；5.5–7.5 谨慎（补条件）；< 5.5 NO-GO。

### Step 5 · 出报告

- 章节与判定块按 `references/report-template.md`。
- **HTML 渲染（本 skill 的默认视觉）**：复制 `assets/report-template.html` 骨架，按 `references/design-tokens.md`、`references/components.md`、`references/echarts-theme.md` 完整套用 8-bit UI；章节→组件映射见 report-template.md 末节。
- 用户只要文字版时，Markdown 按 report-template.md 输出。

### Step 6 · 自检交付

用 html skill 的 shot.py 跑桌面 + 移动自检：0 error 后交付单文件 HTML。重点核对：多列表窄屏横滑不折行、四张图表渲染非空、无 console error、判定块与来源完整。

## 取数与诚信纪律（硬约束）

1. 每个进报告的数字都要有公开来源或显名测算，句末标注来源；估算写"据XX估算"，推断写"可能意味着，待验证"。
2. 不使用训练记忆里的过时市场数字冒充现状；以可溯源检索为准。
3. 数据缺口本身是结论，如实暴露，不硬凑。
4. 区分事实、机构估算、媒体观点与本人推断，措辞强度不超出证据档位。
5. 不把"行业增长"直接等同于"所选细分增长"，必须落到具体细分赛道判断。

## UI 硬约束（8-BIT）

1. **内容保真**：UI 只改视觉。数字、结论、章节、来源清单一字不动；图表数据与图型不改。
2. **无圆角 + 硬阴影**：全部组件直角；层次靠 `box-shadow:4px 4px 0 …` 硬阴影，标题用 `text-shadow:4px 4px 0 var(--yellow),8px 8px 0 var(--navy)`。
3. **字体纪律**：Noto Sans SC + Space Mono，字体链接走 `https://miaoda.feishu.cn/fonts/css2?…`，禁止 Google Fonts 直连；带系统 fallback。
4. **语义色映射**：GO/优势=青、谨慎/警告=黄、回避/风险=粉、中性=lavender。
5. **响应式**：窄屏堆叠单列；3 列以上密集表格加 wide（6 列）/ wide w4（4 列）横滑，禁止逐字折行。
6. favicon 用像素风内联 SVG；背景网格 + 扫描线走 body 伪元素，不占文档流。
