# 类目生意参谋 · 8-BIT 报告版

开店或拓品的**第一站方向判断**：完成三段式生意分析（是不是好赛道、有没有机会、是不是你的机会），并把结论渲染成 8-bit 像素街机风的单文件 HTML 报告。分析结论与视觉是一体的——先做对分析，再套 UI。

## 定位与边界

- **做**：细分赛道级别方向判断、竞争与机会扫描、自身资源匹配、进入路径建议；HTML 报告自带 8-bit 像素街机 UI。
- **不做**：不算毛利/定价/启动资金（留给选品环节）；不判断具体某一款货；不做行业深度研报；不代替实地验证供应链。
- **颗粒度**：细分赛道（如 女装>连衣裙>法式碎花裙），不从大类直接下结论。
- **平台**：用户指定一个平台（小红书 或 拼多多），按该平台镜头分析，不做双平台横向比较。

## 工作流

### Step 1 · 对话挖掘（一次只问当前最关键的一个信息）

1. **指定平台**：小红书 / 拼多多（未定时先问）。
2. **意向赛道**：允许模糊想法，协助收敛到细分层；记录用户原话。
3. **货源**：自有工厂 / 产业带 / 1688 拿货 / 无货源。
4. **内容或达人能力**：能否持续产出内容、有无达人/买手资源、审美或手艺。
5. **资金与库存承受力**、可投入时间、相关经验。

信息不足导致第③段无法打分时，**明确标注"待填"，不强行出 GO/NO-GO**。

### Step 2 · 选定平台镜头

按指定平台读 `references/platform-lenses.md`，用对应指标评估，不混用两套口径。

### Step 3 · 联网公开取证

- 公开检索收集：市场规模/增速、站内热度、竞争格局、价格带、人群、风险信号。
- **多口径并列**：不同机构数字冲突时并列呈现并注明口径，不取单点、不调和编造。
- **查不到就写"公开信息有限/待验证"**，绝不补造；用户可随时补截图或后台数据。
- 合规：只用公开合法内容，不绕过登录态/付费墙/反爬。

### Step 4 · 三段式打分（1-10）

| 段落 | 权重 | 评估维度 |
|---|---|---|
| ① 是不是好赛道 | 30% | 需求规模/搜索热度、增速趋势、季节性与时机、平台大盘适配 |
| ② 有没有机会 | 30% | 竞争密度/同质化、头部集中度、价格带或风格空白、进入门槛 |
| ③ 是不是你的机会 | 40% | 货源、内容/达人能力、资金库存承受力、经验、与平台玩法匹配及差距 |

**综合分 = ①×30% + ②×30% + ③×40%**（③缺失则综合分无法计算）。

**判定阈值（可按用户偏好微调，报告中写明所用阈值）**：≥ 7.5 GO；5.5–7.5 谨慎（补条件）；< 5.5 NO-GO。

## 小红书镜头

**流量逻辑**：内容种草 → 用户晒单/二创 → 笔记挂车/买店/买手带货成交，闭环在社区内完成。审美与情绪驱动，非标、小而美友好。

**① 好赛道看什么**
- 站内搜索热度与近 12 个月趋势（上升/平稳/下降）；
- 相关笔记量级、话题互动量与增速；
- 目标人群（高线城市年轻女性为主）是否匹配；
- 细分风格/场景是否正在起势，而非已饱和。

**② 有没有机会看什么**
- 笔记供给密度与同质化程度：同类风格是否已大量重复；
- 头部达人/品牌集中度，是否存在未被覆盖的细分场景或风格空白；
- 内容门槛：是否需要持续创作养号，个人能否达到；
- 价格带空白：中高客单、设计溢价是否有位置。

**③ 是不是你的机会看什么**
- 能否持续产出种草内容（绘画/拍摄/表达/出镜）；
- 有无个人审美风格、原创设计或手作/改娃手艺；
- 有无达人、买手资源可借力；
- 能否接受浅库存/定制、10–14 周冷启动不盈利。

**常见坑与红线**
- 无授权不做知名 IP 手办/仿制，不碰 1688"伪IP"（缺完整授权链）；
- 不靠一次性爆款，要长期内容经营；
- 手作非标难规模化，明确小而美定位。

## 拼多多镜头

**流量逻辑**：货架 + 搜索 + 活动/百亿补贴，价格与销量驱动，白牌/工厂货走量，供应链成本为王。

**① 好赛道看什么**
- 热销榜/销量规模与大盘走量趋势；
- 是否刚需、复购或季节性稳定；
- 工厂货基础是否成熟、供应链是否好找；
- 大盘是扩容还是存量内卷。

**② 有没有机会看什么**
- 同款数量与价格战烈度；
- 价格带分布，是否存在低价带或品质带空白；
- 头部店铺集中度与新进入者空间；
- 供应链/成本门槛：起订量、供货周期、品质稳定性。

**③ 是不是你的机会看什么**
- 是否有产业带/工厂成本优势；
- 起订量与供货周期能否承受；
- 有无走量运营、活动报名、客服售后经验；
- 能否承受低毛利与价格竞争。

**常见坑与红线**
- 低价内卷导致无利可图，先算成本再决定（本 skill 不算账，只提示需后续测算）；
- 质量与退货售后风险，避免易碎/高售后品；
- 不侵权、不蹭知名品牌外观。

## 两镜头速查对比

| 维度 | 小红书 | 拼多多 |
|---|---|---|
| 驱动 | 审美 / 情绪 / 内容 | 价格 / 销量 / 供应链 |
| 竞争信号 | 笔记密度、风格同质化、达人集中度 | 同款数量、价格战、店铺集中度 |
| 机会空白 | 细分风格/场景、设计溢价 | 低价带、成本优势、品质带 |
| 核心门槛 | 内容创作与审美 | 供应链成本与走量运营 |
| 库存模式 | 浅库存/定制/孤品友好 | 批量走量、周转快 |
| 冷启动 | 内容积累 10–14 周（经验值） | 活动/价格起量，节奏快 |
| 主要红线 | 版权/IP 授权、伪IP | 低价内卷、质量售后、侵权 |

## 2. 是不是好赛道：市场空间与增速

- 市场规模：多口径并列（来源 + 口径 + 数值），不强行统一。
- 增速趋势：近 12 个月 / 近年走向，增长驱动与制约。
- 季节性与当前时机：全年稳定 / 季节脉冲，现在处于上升还是降温。
- 平台大盘适配：该平台内该赛道的热度证据。
- 小结：好赛道是否成立，给 ① 段分数与理由。

## 3. 有没有机会：竞争与空白

- 竞争格局：头部集中度、主要玩家、同质化程度。

- 进入门槛：内容门槛（小红书）或供应链/成本门槛（拼多多）。
