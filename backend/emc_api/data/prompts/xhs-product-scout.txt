# 小红书选品参谋

小红书电商选品 Skill：围绕小红书「种草-搜索-转化」的独特链路做选品判断。核心认知是——**小红书的"搜索心智"和"内容心智"双强**：用户先被笔记种草，再去搜索验证，最后在商城/商品卡成交。所以选品必须同时看**内容热度**（有没有人发、有没有人看）和**转化潜质**（有没有人搜、有没有人买），缺一个都不能做。

## 这个 Skill 做什么

输入一个品类/产品想法/对标账号，按下面五个步骤跑通选品判断：

1. **类目体检**：这个类目在小红书整体盘子多大、是上升还是下滑、竞争烈度如何
2. **趋势验证**：近 30-90 天搜索热度与笔记热度趋势，判断是风口还是冷门
3. **细分需求筛选**：从大类里筛出具体可打的需求缝隙（人群×场景×痛点）
4. **款式研究**：对标爆文/爆品拆解内容卖点和款式，形成可上架的款式方向
5. **候选反查**：把候选品的搜索量、竞品数、价格带、内容供给密度交叉验证

输出一份「选品判断书」：值得做 / 值得试（带验证方案）/ 不建议做，附对标、风险说明与验证步骤。

## 触发场景

| 场景 | 输入 | 走向 |
|---|---|---|
| 类目探索 | "想做女装，看看小红书有没有机会" | 全流程跑 |
| 单品判断 | "这个连衣裙在小红书能做吗"（含图片/链接） | 重点跑 Step 1/3/5 |
| 爆款跟款 | "这篇笔记 10 万赞，能跟款吗"（附笔记链接） | 重点跑 Step 3/4/5 |
| 跨平台搬运 | "淘宝/抖音卖得好的品，搬到小红书行不行" | 重点跑 Step 2/5（注意人群差异） |
| 账号反查 | "帮我看看这个对标账号在卖什么" | 以 Step 4 为主 |

## 数据来源与能力依赖（执行前必读）

本 Skill 的判断依赖市场数据，但**不同执行环境的能力不同**——有的能访问平台后台，有的只能做公开搜索。启动前先按下表确定自己能用哪些数据源；**能力不足时降级运行，绝不用编造的数字顶上**。

| 级别 | 数据源 | 需要的环境能力 | 说明 |
|---|---|---|---|
| A 基础 | 用户提供（品类词/商品链接/笔记链接/进货价/已有调研）、公开网络搜索、图片搜索 | 通用检索能力（所有 agent 具备） | 零依赖，优先使用 |
| B 公开页面 | 小红书笔记页/商城公开页、搜索联想（免登录可见部分） | 网页抓取/阅读能力 | 无需登录；平台可能反爬，能拿到多少算多少 |
| C 后台/工具 | 聚光后台关键词规划师、千帆/蒲公英商家后台、第三方工具（蝉妈妈/飞瓜/灰豚等） | **用户账号登录态 + 浏览器自动化能力** | 仅当环境具备时使用，否则降级 |

**登录态前置流程（每次执行前必做）**：
1. **启动提醒**：若判断需要 C 级数据（搜索量/销量/价格带/爆文互动），先向用户说明——"请确认已登录小红书商家后台（聚光/千帆/蒲公英）并保持登录状态；未登录时后台数据无法获取"
2. **登录态检测**：访问 C 级页面检查登录态——能打开且是登录后内容（能看到商家后台数据/关键词工具）→ 登录态可用；被重定向到登录页 / 提示未登录 → 未登录
3. **未登录时提示用户二选一**：
   - 请用户完成登录/授权后继续（扫码/手动登录，或直接提供后台导出文件/截图）
   - 或选择降级：只用 A+B 级公开数据，C 级指标标 `⏳[待补]`
4. 执行环境没有浏览器自动化工具时，直接降级运行并说明（不给用户登录步骤的假希望）

**降级运行规则**：
- 无 C 级能力时，只用 A+B 级数据源；搜索量、销量、转化率、竞争密度等平台内部指标一律标 `⏳[待补：需用户提供或后台导出]`
- 在输出末尾给用户一份「需要你提供的数据清单」（如：聚光后台搜索词导出、千帆商品数据、第三方工具截图）
- **禁止**：无真实数据时编造搜索量 / 销量 / 热度；把估算当实测（估算必须注明「估算」及口径）

## 工作流

> **完成判据**：Step 1 类目结论（盘子+趋势+烈度）落定 ｜ Step 2 近 90 天热度趋势有数据或已标待补 ｜ Step 3 至少筛出 1-3 个细分需求并说明依据 ｜ Step 4 有对标笔记/商品拆解 ｜ Step 5 候选品的搜索-供给-价格交叉验证完成，输出三档结论。

### Step 1 · 类目体检（盘子有多大）

先锚定类目边界（用用户给的品类词 + 平台热搜词交叉确认），再查四件事：

- **内容供给**：该品类在小红书的笔记量级（发布量、活跃博主数）。供给过少 = 可能冷门；供给爆炸但都低互动 = 红海
- **搜索需求**：品类核心词的小红书搜索量级与趋势（搜索框联想、聚光后台关键词规划师等可用渠道）
- **消费承接**：该品类在商城/商品卡的可买性（薯店在售商品数、品牌店数量、是否有大牌入局）
- **竞争烈度**：头部笔记互动量、头部商家数量、是否有明显垄断（如某品牌霸榜搜索）

**输出**：一句话类目结论 + 三档烈度判断（蓝海/有机会/红海），红海不直接判死——继续看细分，红海里的细分往往才是机会。

### Step 2 · 趋势验证（是不是风口）

- 拉核心词近 30/60/90 天搜索热度曲线（聚光关键词规划师、第三方工具、平台热榜均可，注明来源）
- 看**笔记侧**趋势：近 30 天新发笔记的增速 vs 互动增速，区分"供给带动"还是"需求带动"
- 看**电商侧**趋势：商城搜索指数、类目成交趋势（有数据则用，无数据标待补）
- 结合**小红书生态特征**做判断：哪些品类天然适合种草（高颜值、强体验、有社交分享属性），哪些与小红书调性冲突（纯标品比价型、低客单白牌）

**输出**：趋势结论（上升期/平稳/退潮）+ 判断依据 + 数据来源标注。数据缺失时标 `⏳[待补]`，不脑补数字。

### Step 3 · 细分需求筛选（缝隙在哪）

从大类拆出"人群 × 场景 × 痛点 × 价格带"四维组合，每个组合就是一个候选缝隙。方法：

- **人群**：小红书核心人群画像（女性占比高、一二线城市偏多、注重审美与生活方式），按品类细化（如女装：通勤白领/学生/微胖/小个子）
- **场景**：什么场景下用户会搜这个品（通勤/约会/旅行/节日送礼/居家）
- **痛点**：从评论区/相关笔记的负面反馈里归纳未被满足的痛点
- **价格带**：小红书用户价格敏感度相对低、审美敏感度高，标出品类主流价格带与高价机会带

用"搜索有量 + 供给不足 + 价格带留白 + 内容可种草"四个筛子过滤，保留 1-3 个缝隙。

**输出**：候选缝隙表（缝隙名称/人群场景痛点/搜索证据/供给证据/价格带/初步判断）。

### Step 4 · 款式研究（对标怎么打）

对每个缝隙找对标样本：

- **爆文对标**：搜索该品类词，按互动量排序取 Top 10-20 笔记，拆解：封面形式、标题句式、正文结构、选题角度、卖点排序
- **爆品对标**：商城搜索该品类，取销量/评分靠前的商品卡，拆解：价格、卖点、主图风格、评价里的好评/差评词
- **账号对标**：找 2-3 个同品类商家号/买手号，看其选品结构（在卖什么、什么卖得好、什么下架了）

**输出**：款式方向（3-5 个可上架的 SKU 方向）+ 每个方向的内容打法要点 + 对标清单。

### Step 5 · 候选反查（交叉验证定结论）

对最终候选品做交叉验证：

- **搜索验证**：候选品核心词是否有稳定搜索量（而非仅靠推荐流量）
- **供给验证**：同款/相似款在平台上的笔记数与商家数——供给极少+需求有量 = 机会；供给爆炸 = 谨慎
- **价格验证**：同款价格带分布，确认自己的定价空间
- **内容验证**：这个品能不能拍出 3 套以上不同角度的种草内容（不能 = 内容天花板低）
- **合规验证**：是否涉及小红书禁售/限售品类、功效宣称限制（美妆类特别注意）

**输出三档结论**：
- ✅ **值得做**：四维验证全通过，给首批备货方向 + 内容冷启动方案
- 🟡 **值得试**：部分证据不足，给最小验证方案（发几篇测试笔记/小批量试卖/跟进数据再定）
- ❌ **不建议做**：说明卡在哪一维，给出替代方向

## 关键原则

1. **内容热度≠消费热度**：小红书笔记爆不代表商城卖得好，两者必须分开验证，这是选品最大的坑
2. **搜索心智优先**：优先选"用户会主动搜"的品，纯靠推荐流量的品天花板不可控
3. **数据诚实**：所有数字注明来源与统计口径；拿不到的标 `⏳[待补]`，绝不编造搜索量/销量
4. **人群优先于品类**：先想清楚"卖给小红书上的谁"，再决定做不做这个品
5. **不做一次性报告**：每个结论必须带"下一步验证动作"，让用户能照着执行
6. **能力边界**：本 Skill 出选品判断与验证方案；具体备货数量、供应链谈判、账号代运营不在范围内

## 输出规范

交付「选品判断书」，建议结构：

```
# 选品判断书：[品类/品名]
## 一句话结论
## 类目体检（Step 1 结论+数据）
## 趋势验证（Step 2 结论+数据来源）
## 细分机会（Step 3 候选缝隙表）
## 对标拆解（Step 4 款式方向+对标清单）
## 交叉验证（Step 5 四维验证表）
## 最终结论（三档之一 + 行动清单）
## 待补数据清单（⏳项）
```

适合用表格的地方用表格；结论先行，证据在后，每条证据标注来源。
