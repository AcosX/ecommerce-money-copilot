# 拼多多选品参谋

拼多多选品 Skill：围绕拼多多「货架+价格力」的独特逻辑做选品判断。核心认知——拼多多的流量高度集中在**搜索**和**比价**：用户带着明确需求来搜，谁的价格和销量有优势谁拿流量；同时平台强推**价格力**（同款低价拿更多曝光）和**活动流量**（百亿补贴/秒杀/9.9 包邮）。所以选品必须同时看**搜索需求量**、**价格带竞争**和**供应链价格优势**，这三个缺一个都做不起来。

## 这个 Skill 做什么

1. **类目体检**：类目盘子、增长性、竞争烈度（商家数与头部集中度）
2. **趋势验证**：近 30-90 天搜索热度与季节节奏
3. **价格带与细分筛选**：找出"有量+有价格缝隙"的细分（价格带是拼多多选品第一筛）
4. **竞品款式研究**：拆解在售爆款的销量、价格、SKU、卖点
5. **候选反查**：搜索-价格-供应链-合规交叉验证

输出「选品判断书」：值得做 / 值得试（带验证方案）/ 不建议做，附对标、价格测算与风险说明。

## 触发场景

| 场景 | 输入 | 走向 |
|---|---|---|
| 类目探索 | "想做家居百货，拼多多有机会吗" | 全流程 |
| 单品判断 | "这个商品在拼多多能做吗"（含链接/图） | 重点 1/3/5 |
| 跟款 | "这个款卖爆了，我能跟吗" | 重点 3/4/5 |
| 跨平台搬运 | "1688/淘宝的品搬到拼多多" | 重点 2/5（价格重算） |
| 比价选品 | "帮我找这个品类的价格缝隙" | 重点 3 |

## 数据来源与能力依赖（执行前必读）

本 Skill 的判断依赖市场数据，但**不同执行环境的能力不同**——有的能访问平台后台，有的只能做公开搜索。启动前先按下表确定自己能用哪些数据源；**能力不足时降级运行，绝不用编造的数字顶上**。

| 级别 | 数据源 | 需要的环境能力 | 说明 |
|---|---|---|---|
| A 基础 | 用户提供（品类词/商品链接/进货价/已有调研）、公开网络搜索、图片搜索 | 通用检索能力（所有 agent 具备） | 零依赖，优先使用 |
| B 公开页面 | 拼多多商品公开页、搜索联想/热词（免登录可见部分） | 网页抓取/阅读能力 | 无需登录；平台反爬严格，能拿到多少算多少 |
| C 后台/工具 | 拼多多商家后台、多多情报/推广后台关键词工具、第三方工具（多多参谋/蝉妈妈等） | **用户账号登录态 + 浏览器自动化能力** | 仅当环境具备时使用，否则降级 |

**登录态前置流程（每次执行前必做）**：
1. **启动提醒**：若判断需要 C 级数据（搜索量/销量/价格带/同款数据），先向用户说明——"请确认已登录拼多多商家后台（商家后台/多多情报/推广后台）并保持登录状态；未登录时后台数据无法获取"
2. **登录态检测**：访问 C 级页面检查登录态——能打开且是登录后内容（能看到商家后台数据/关键词工具）→ 登录态可用；被重定向到登录页 / 提示未登录 → 未登录
3. **未登录时提示用户二选一**：
   - 请用户完成登录/授权后继续（扫码/手动登录，或直接提供后台导出文件/截图）
   - 或选择降级：只用 A+B 级公开数据，C 级指标标 `⏳[待补]`
4. 执行环境没有浏览器自动化工具时，直接降级运行并说明（不给用户登录步骤的假希望）

**降级运行规则**：
- 无 C 级能力时，只用 A+B 级数据源；搜索量、销量、转化率、竞争密度等平台内部指标一律标 `⏳[待补：需用户提供或后台导出]`
- 在输出末尾给用户一份「需要你提供的数据清单」（如：商家后台搜索词导出、多多情报关键词数据、第三方工具截图）
- **禁止**：无真实数据时编造搜索量 / 销量 / 热度；把估算当实测（估算必须注明「估算」及口径）

## 工作流

> **完成判据**：Step 1 类目结论落定 ｜ Step 2 趋势有数据或已标待补 ｜ Step 3 筛出 1-3 个细分（含价格带依据）｜ Step 4 有对标爆款拆解 ｜ Step 5 交叉验证完成，输出三档结论。

### Step 1 · 类目体检（盘子与烈度）

- **市场规模**：类目下的在售商品数、销量级（用平台搜索排序与销量数据估计，注明口径）
- **需求规模**：核心词搜索热度（平台搜索联想、推广后台关键词工具）
- **供给与集中度**：头部商品销量占比、品牌/工厂店占比、是否有垄断型大卖
- **活动适配**：该品类是否常见于百亿补贴/秒杀/9.9 包邮（常见 = 价格战激烈）

**输出**：类目结论 + 烈度三档（蓝海/有机会/红海）。红海不判死——拼多多红海里仍有"价格带缝隙+细分化"机会。

### Step 2 · 趋势验证（节奏与窗口）

- 核心词近 30/60/90 天搜索趋势（有数据则用，注明来源）
- 季节性节奏：该品类的旺季/淡季、大促节奏（618/双11/年货节）
- 平台政策风向：平台当前扶持什么（价格力/新品牌/白牌工厂），顺风做事

**输出**：趋势结论（上升/平稳/退潮/季节窗口）+ 依据 + 来源。缺失标 `⏳[待补]`。

### Step 3 · 价格带与细分筛选（拼多多第一筛）

拼多多选品的核心公式：**需求有量 × 价格带留白 × 供应链能打**。

- **价格带扫描**：按价格段统计在售商品数与销量分布，找"销量集中在哪个价格带""哪个价格带供给少"
- **细分筛选**：人群×场景×痛点×价格带四维拆（如家居：学生宿舍/租房/宝妈收纳）
- **价格力测算**：估算"同款最低价 + 运费 + 平台扣点"后自己还有没有利润空间——**毛利算不过来直接否**，拼多多没有低价就不进流量池
- **非标品机会**：标品拼价格，非标（有款式/设计差异）拼款式，非标是中小卖家更现实的战场

**输出**：候选细分表（细分/价格带证据/供给证据/毛利估算/初步判断）。

### Step 4 · 竞品款式研究（爆款怎么打的）

对每个细分找对标：

- **爆款拆解**：平台搜索该品类，按销量取 Top 10-20：价格、销量级、主图风格、标题结构、SKU 组合、评价结构与差评词
- **同款比价**：同款/相似款的价格分布与销量差异，找出"贵了没量、便宜有量"的临界价格
- **供应链反查**：同款在 1688 的拿货价区间（用户提供或可查渠道），估算利润空间

**输出**：款式方向（3-5 个 SKU 方向，含建议定价区间）+ 对标清单 + 毛利测算。

### Step 5 · 候选反查（交叉验证定结论）

- **搜索验证**：候选品核心词搜索量是否稳定（拼多多搜索流量为主，搜不到 = 没量）
- **供给验证**：同款在售商品数——供给少+需求有 = 机会；供给爆炸 = 拼价格
- **价格验证**：确认自己定价在同款价格带中有竞争力（价格力分）
- **供应链验证**：拿货价/生产成本 + 物流成本是否能支撑低价仍有利润
- **合规验证**：平台禁售/限售类目、品牌侵权风险（白牌避开外观专利）、功效宣称限制

**输出三档结论**：
- ✅ **值得做**：全通过，给首批 SKU 方向 + 定价建议 + 冷启动方案（活动报名/推广节奏）
- 🟡 **值得试**：部分证据不足，给最小验证方案（小批量上架测款/投少量搜索推广看数据）
- ❌ **不建议做**：说明卡点（多为价格力不足或毛利算不过来），给替代方向

## 关键原则

1. **价格力是入场券**：拼多多没有价格优势就没有流量，先算毛利再谈选品
2. **搜索量是命根**：优先"用户会主动搜"的品，推荐流量占比低且不可控
3. **标品拼价、非标拼款**：中小卖家优先非标细分，避开标品价格战正面
4. **数据诚实**：销量/搜索量注明来源与估算口径，缺失标待补，不编数字
5. **不做一次性报告**：每个结论带"下一步验证动作"
6. **能力边界**：出选品判断与验证方案；供应链谈判、具体工厂对接不在范围内

## 输出规范

交付「选品判断书」：

```
# 选品判断书：[品类/品名]
## 一句话结论
## 类目体检（Step 1 结论+数据）
## 趋势验证（Step 2 结论+来源）
## 价格带与细分机会（Step 3 表）
## 对标拆解（Step 4 款式方向+定价+毛利）
## 交叉验证（Step 5 四维验证表）
## 最终结论（三档之一 + 行动清单）
## 待补数据清单（⏳项）
```

表格优先，结论先行，证据在后并标注来源。
