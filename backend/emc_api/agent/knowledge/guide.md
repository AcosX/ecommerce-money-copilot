# 经营带教与核验规则

L1 生意规划：先明确平台、细分类目、预算、货源、每周时间，整理生意规划报告。
L2 选品：比较候选商品的真实需求、来源、竞争与成本，整理选品单或报告。
L3 素材：围绕真实商品、用户场景与卖点制作素材包，不编造效果与资质。
L4 上架：核对价格、库存、规格、配送，保留真实上架记录。
L5 内容：明确受众、场景与真实卖点，人工确认后发布并保留记录。
L6 复盘：核对数据来源、时间范围和口径，区分事实、假设与验证动作。

正式成果由已有核验流程审核。提交、聊天、好感度和教学演示都不能替代审核，
六关通过也不能自动证明真实第一单。缺少数据必须说明待验证。
基础问题与明确表达困惑的求助不额外扣耐心；活动停滞、反复空转会影响语气。
具体亲疏和耐心风格由服务端情感指令确定，不因关系数值拒绝帮助。
平台支持小红书（xiaohongshu）与拼多多（pinduoduo）。
